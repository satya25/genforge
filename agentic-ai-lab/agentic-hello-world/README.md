# Agentic Hello World

## Overview
This project is the **first demo application** in the GenForge Agent Development workshop series.  
It introduces participants to the basics of setting up a Python project, creating a minimal folder structure, and launching a simple AI Agent using a lightweight Ollama model.

## Objectives
- Learn how to scaffold a generic agentic project.
- Understand the purpose of each folder and file in the structure.
- Configure environment and dependencies.
- Run a minimal "Hello World" agent application with Streamlit.

## Folder Structure
```
agentic-hello-world/
  ├── app.py                  # Streamlit entry point
  ├── config/                 # Configuration files
  ├── data/                   # Raw and processed data
  ├── docs/                   # Documentation and setup guides
  ├── notebooks/              # Jupyter notebooks
  ├── src/                    # Source code (agents, utils)
  ├── tests/                  # Unit tests
  ├── requirements.txt        # Python dependencies
  ├── LICENSE                 # License file
  ├── .gitignore              # Git ignore rules
  └── README.md               # Project overview
```

## Quick Start
1. Edit and run `project_set_up.sh` to scaffold the project.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`.
4. Launch the app: `streamlit run app.py`.
